Advanced Regex Rules

Regular expressions are patterns used to check whether text follows a particular format. Your JavaScript validators perform the actual checks.

  • Title: ^(?=.{3,120}$)[\p{L}\p{N}][\p{L}\p{N}\s.,:;!?()'’&+/#_-]*$

    Requires 3–120 characters, starts with a letter or number, and allows common punctuation.

  • Date: ^\d{4}-\d{2}-\d{2}$

    Checks the YYYY-MM-DD format. JavaScript must also verify that the date exists on the calendar.

  • Duration: ^\d+$

    Accepts whole numbers only. JavaScript additionally restricts the value to 1–1440 minutes.

  • Tag: ^[\p{L}\p{N}]+(?:[ _-][\p{L}\p{N}]+)*$

    Allows letters and numbers separated by single spaces, underscores or hyphens. JavaScript also checks the length.

These patterns use Unicode property escapes where appropriate, so titles and tags can include letters from different languages. Regex alone is not enough to validate a real calendar date or prevent every expensive regex pattern.
